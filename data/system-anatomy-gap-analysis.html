6b. JSONL Schema Definitions

Every cross-boundary file has an exact schema. Violations = bugs.

cortex.jsonl — Body → Cortex task dispatch

Written by: OpenClaw ThematicScheduler when hardness ≥ 4

Read by: IntentGuard cortex-worker (polls every 30s)

{
  "id": "ctx-{ISO_DATE}-{SEQ}",         // unique task ID
  "room": "builder",                     // target cognitive room
  "prompt": "Implement the Qwen...",     // work description (max 2000 chars)
  "hardness": 4,                         // 4=Opus, 5=Opus+human review
  "sovereignty": 0.70,                   // current score at dispatch time
  "categories": ["implementation"],      // trust-debt categories
  "tesseractCell": "C1",                 // source ShortRank cell
  "themeSlot": "afternoon-building",     // which schedule slot triggered this
  "createdAt": "2026-02-18T20:30:00Z",
  "status": "pending",                   // pending → claimed → completed | failed
  "claimedBy": null,                     // worker ID when claimed
  "claimedAt": null
}
