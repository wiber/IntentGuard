6. What Local LLMs CAN Do via Terminal

Qwen 14B cannot directly execute commands, but the architecture already supports local LLM → terminal via this chain:

  1. Qwen generates a task prompt (JSON with room, action, priority)
  2. Runtime routes it to claude-flow-bridge.ts
  3. Claude Flow spawns an agent (Claude Opus/Sonnet) in the terminal room
  4. Agent executes the command in iTerm/Kitty/Terminal
  5. OutputPoller captures the result
  6. Qwen reads the output and decides next step

This is the "Qwen as CEO, Claude as hands" model. Qwen thinks (free), Claude acts ($).

Future: For simple tasks (file writes, JSON edits, git operations), Qwen could execute directly via a sandboxed shell skill — no Claude needed.
